# parallel_pi

parallel_pi 用 Git 分支组织开发记录，用思路分支组织对话探索路径。

## Language

**Git 分支**：代码开发路线，在界面中对应一行或一列，其下的对话使用该分支的当前代码。
_Avoid_：不加限定的“分支”（可能与思路分支混淆）

**思路分支**：归属于一个 Git 分支的对话探索路径；一个 Git 分支可包含多条思路分支。它从已有对话上下文分出，使用所在 Git 分支的当前代码，不对应独立代码版本；分叉或切换思路不会恢复历史文件。
_Avoid_：代码分支、代码快照、模型内部推理过程

**文件记忆**：在固定目录持久保存的会话变更记录、结论与长期偏好，供后续会话按任务需要选择性读取。
_Avoid_：完整聊天历史、自动继承的全部上下文

**会话（Session）**：可持续多轮交流的工作记录，对应地图上的一个节点；继续会话不创建新节点，新建接续或独立会话会创建新节点。
_Avoid_：单轮消息、单次执行

**会话节点**：一个 session 在对话地图中的表示；“地图卡片”仅是它可能的视觉呈现，不是独立对象。
_Avoid_：消息卡片、代码快照
