## 辅助面板的字段与顺序

| 面板 | 主要内容 | 主操作 | 失败反馈 |
| --- | --- | --- | --- |
| 添加项目 | 本机目录、已识别仓库、已有改动提示 | 添加项目 | 目录不可用/非仓库；保留路径 |
| 新建分支 | 名称、起点、未提交改动不复制的提示 | 创建分支 | 名称冲突/工作区准备失败 |
| 全局 pi 设置 | provider、凭据状态、API key 输入及适用的连接选项 | 保存连接配置 | 字段错误/保存失败；不暴露密钥 |
| 项目模型 | 当前来源、provider/model、继承选项 | 保存项目默认 | 模型不可用，不自动替换 |
| Session 模型 | 当前选择、下一次执行生效说明 | 使用此模型 | 保持原选择并显示原因 |
| 分支队列 | 当前执行、等待提问、后续项、暂停原因 | 停止 / 恢复队列 | 未收束时不允许假恢复 |
| 分支变更 | HEAD、暂存/未暂存、文件选择、diff、提交消息 | 提交选定修改 | 内容变化/钩子失败保留输入 |
| 文件记忆 | 索引、记录状态与范围、来源、正文编辑 | 保存纠正 | 冲突差异或保存失败，可重试 |

上述辅助面板字段和失败处理属于规格中的设计默认值；图册仅绘制三个主要画面，没有声称完成全部高保真页面。
