# M4b：原生 provider 连接编辑

设置面板新增连接编辑，直接写固定版 pi 的 `models.json`；不另建模型注册表。支持 Base URL、OpenAI Chat Completions / Responses / Anthropic Messages API 格式、模型 ID 与图片输入能力。已有其他 API 格式可保留，其他参数继续由原生文件管理。删除明确说明自定义模型及内联认证随连接移除，独立 auth 凭据保留。

读取使用原生 `ModelConfig`，只投影连接与模型元数据。带用户信息、查询参数或片段的地址不回显，已有 key/header 不回显、不执行。写入先校验输入和完整候选 schema，再用与设置相同的文件锁及进程级 HMAC 修订核对原文；异步校验期间的外部修改也会在锁内被拒绝。读取 JSONC 沿用原生注释/尾逗号解析，保存重排缩进并移除注释；未知字段、其他 provider/model、原生高级参数和未编辑的认证值保留。

原生校验器仅接受文件路径，因此在系统临时目录中创建 0700 私有目录与 0600 快照，正常完成或失败均删除；进程被强杀时可能留下私有临时快照。源文件仍为唯一配置来源。原生文件后端按原方式写入，不能约束不遵守文件锁的编辑器，不宣称断电原子保存。
