# M4e1：Git 工作区变更预览

分支地图和会话地图浮层均提供“分支变更”入口。弹窗展示真实 worktree、ref、基准 HEAD，以及全部暂存/未暂存/未跟踪路径；选择路径后分别显示 HEAD→暂存区、暂存区→工作区的原生 diff。重命名按删除和新增两条整文件路径显示，不把另一路径隐式加入用户选择。内容以纯文本展示，不归因于所选 session。

部分暂存文件明确提示交由外部 Git 工具处理；暂存删除后重新创建的同一路径合并为一个部分暂存条目。冲突、子模块与嵌套仓库标记为外部处理。二进制显示原生摘要和对象 ID；符号链接显示链接内容。字面路径含通配语法、换行、中文时不被扩展为其他路径。

每次预览比较读取前后的修订，修订包含 HEAD、ref、完整索引以及变更文件的字节/模式；读到变化则拒绝返回混合快照。正常预览不修改 Git index 或工作区。这里不是跨外部编辑器的文件系统事务，不能防止读取之后的新修改；后续提交必须重新核对同一修订。

应用先持久化 `inspect-git` 操作意图，再由 Linux 监督器运行独立 worker。分支维护占用直到子进程收束才释放；期间排队任务不启动。中断读取不自动重放，恢复后分支保持暂停；收束证据不足时保持 recovering。读取错误保留上一次视图并明确标明过期，用户可重新读取。
