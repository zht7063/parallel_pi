# M4c：工作区记忆管理

已接入工作区显式初始化、原生召回、记录查看和纠正。Git 策略默认 track、可选择 ignore，已有策略保留；私有 local 排除，不自动提交。每个 worktree 独立操作，读取未初始化目录不创建记忆。

查看保留原生类型、状态、scope、来源文件与正文；incident 的适用/失效边界单独展示。候选可以进入原生召回结果，但保留 candidate 状态与未确认提示。纠正支持原生允许的状态、摘要、正文和 scope，晋升必须提供正文；失效/替代使用原生状态并在正文记录原因及替代 ID，不提供隐式删除或自动合并。

保存前持久化意图；查看和写入都占用同分支维护名额，使用现有 Linux 进程监督器。带修订号的原生事务与请求回执共同提交；故障暂停分支，重启后不自动重放，重试只核对原意图。明确暂不重试保留记录，不回滚可能已写入的文件，也不自动恢复队列。
