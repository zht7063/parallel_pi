# M3 地图与会话：阶段证据

2026-09-17，Linux，固定 Node/pi/MWF 基线同 M2。M3 完成地图与会话里程碑，不代表完整 MVP 或 M4/M5 已完成。

| 交付 | 行为与证据 |
| --- | --- |
| 全局地图 / 会话 / 浮层 | `ProjectMap.vue` 复用本地关系图、远端行、预览与视口控制；`MapThumbnail.vue` 高亮当前会话并反映运行状态；非模态地图在缩略图下方，不阻挡第二次点击。`tests/map.spec.ts` 验证双击切换、缩略图返回、显式按钮、Enter、Esc 分层关闭与焦点恢复 |
| 关系与节点 | 稳定 session/path ID、continue/fork 来源边；多根森林自动布局，连线标明接续/分叉；节点展示最近状态、活动时间、简短结果。`tests/map-layout.test.ts` 验证多根、边类型、路径身份、跨列保护和损坏关系不死循环；浏览器验证真实接续与 fork 连线 |
| 视口与多项目 | 全局和浮层分别按项目持久保存比例、位置、选择和预览；切换项目恢复会话与草稿，窗口变窄保留坐标并可定位当前节点。`tests/map.spec.ts` 验证独立视口、刷新、项目切换、390px、草稿与零自动运行；真实慢工具执行期间切到其他会话/项目仍在运行，占用者可见 |
| 接续 / 独立 | 接续保留路径并创建空上下文；独立建立新路径；请求 ID 固定原始创建内容，后续模型修改不破坏幂等。`tests/harness.test.ts`、`tests/browser.spec.ts` 验证空上下文、来源、恢复与不自动执行 |
| 原生 fork | 固定 SessionManager before-user 分叉，完整原生快照写不可变回执，再无覆盖发布；首条消息无需伪造 assistant 或运行模型。选中内容及图片成为草稿；源文件/工作区不改写。`tests/engine.test.ts` 验证首条、中间、图片、原生可用位置、源保护、冲突文件和发布恢复；`tests/harness.test.ts` 验证丢失确认后的对账、幂等和新会话继续；浏览器验证弹层边界、图片草稿及刷新 |
| Git 本地与远端 | 建分支先记录预期 HEAD/操作 ID；导入远端前重新 fetch，创建跟踪分支；失败保留旧缓存并显示过期，名称冲突保留输入，不切换当前工作区。真实 Git 应用测试覆盖远端 tip 更新、缓存失败、写入后丢失确认、dirty 保留；浏览器覆盖无效名称修改和远端导入 |
| 长历史与阅读位置 | 全局快照只带每会话最近 40 条消息，`/api/history` 以原生 entry ID 分页，最大页 100；旧游标不因后续追加而位移。应用缓存测试覆盖 95 条及并发追加，HTTP 测试覆盖真实 pi 历史/边界/非法游标。浏览器 95 条 UI 专用 fixture 覆盖失败、重试、旧位置 fork 预览、阅读位置恢复；不把该 fixture 声称为 95 条真实模型对话 |
| 队列状态 | 列头反映当前执行/等待状态；会话显示同分支占用者、等待序列位置。浏览器验证真实慢工具、排队、停止和跨项目导航；M2 的实际调度与恢复回归保留 |

检查：`npm run check`（30 个 Node 测试，架构/类型/格式）；`npm run build`；`npm run test:browser`（4 个场景）；UI strict 审查 0 errors / 0 warnings，见 `m3-ui-audit.json`。浏览器仍需 development.md 所述本机字体/运行库环境。已核对 `test-results/map-overlay-narrow.png`、`fork-dialog-narrow.png`；这些本机截图由测试重现，不入 Git。

限制与后续义务：地图节点按 40 个分批渲染，项目/节点元数据仍整体读取；SQLite 单 JSON 元数据规模限制延续 M2，不声称无界规模。原生 fork 辅助进程不加载扩展 hook；固定入口与升级义务见 native-contracts.md。纯图片消息不出现在固定版原生可分叉列表，界面遵循它。模型配置/信任、MWF 初始化召回修订、diff/提交、备份和 macOS 本机 Linux 启动打包仍在 M4；A01–A16 全量验收、真实外部模型与更多故障窗口在 M5。
