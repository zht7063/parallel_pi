## 设计一致性检查结论

| 检查点 | 收敛结果 |
| --- | --- |
| 浏览状态与执行状态 | 单击/双击、切换项目和关闭网页不会隐式提交或停止任务 |
| 双击入口 | 保留显式按钮；详情/地图面板不移动或覆盖第二次点击目标 |
| 思路与代码 | 一个节点一 session；历史分叉仍使用当前 Git 分支工作区 |
| 失败与队列 | 等待回答占用执行名额；失败/停止暂停列；恢复不重放原工具 |
| 模型变更 | 项目/会话选择与全局凭据分工明确；入队记录有效模型 |
| 记忆保存 | 运行成功与记忆保存成功分开；重试保存不等于重跑 agent |
| 草稿与项目切换 | 按项目/session 保存；后台任务继续，入口展示状态 |
| Git 操作 | dirty 修改保留；分支拉取不自动 merge；提交由用户明确触发 |

设计具备进入下一阶段的规格和验收基础；并不表示技术可行性已通过运行测试。
