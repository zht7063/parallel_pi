# 文件记忆：参考与适配讨论

日期：2026-09-16。状态：产品方向及沿用 Memory with Files 的记忆设计思路已确认；具体存储与集成方案仍为建议。

## 已确认方向

- 思路分支从属于 Git 分支：项目 → Git 分支 → 思路路径及会话。每条思路路径归属于一个 Git 分支，共享其当前工作区。
- 使用固定子目录保存会话变更、结论、持久偏好等，后续会话由 agent 选择性读取。
- 用户可查看和纠正记忆；记忆写入失败须明确提示，不能显示为保存成功。关键记忆写入失败暂停该列，允许重试或由用户明确继续。
- 项目偏好、结论的分类、作用域、候选状态、按需召回及更新失效机制，沿用 Memory with Files 的设计思路，不另设独立的偏好共享政策。此决定不等于已选定运行时复用或跨 worktree 实时同步方案。
- `.memory/` 是目录名示例；用户要求参考 memory-with-files，尚未要求安装或初始化。
- 文件记忆用于跨会话延续；继续原会话、从历史节点分叉仍使用内核原生上下文。记忆不替代完整对话记录，也不代表历史代码快照。

## 建议：分开保存会话记录与长期知识

建议在同一个记忆入口下区分两类内容：

- 会话记录：每个 session/run 分别保存变更摘要、结果、验证、未完成事项、来源链接；可记录临时进展，但不把它们当成永久规则。
- 长期知识：整理后的偏好、决策、知识和可复用经验；沿用 MWF 的状态、作用域、来源与失效规则。

概念结构如下，仅表示 parallel_pi 拟议结构，不是现有 MWF schema：

```text
<记忆目录>/
  index.md
  preferences/
  decisions/
  knowledge/
  incidents/
  candidates/
  sessions/<session-id>/
    handoff.md
    runs/<run-id>.md
```

每个会话的 handoff 独立维护，避免不同思路覆盖一份全局 handoff。索引是可重建的路由信息，不是另一个结论来源。

## 已确认：沿用 MWF 的记忆语义

项目偏好和结论按 MWF 的分类、scope 与状态管理：先读取索引，再根据当前任务的路径、组件、工具和操作召回相关内容；明确持久的规则可保存，含糊或未验证内容保留为候选，临时指令不提升为长期偏好。

当前用户要求、正式项目规则和已验证事实优先于记忆。结论保留适用条件、失效条件与替代关系；不能因它曾在某会话出现就认为始终有效。

此前提出的“项目／Git 分支／思路”三级范围仅作为可能的适配分析，不作为另一套已确定的记忆协议。parallel_pi 需要记录来源会话及所属分支，跨 worktree 的实际存储和读取方式在集成阶段验证；不假定原有 scope 已支持这些身份字段。

从历史节点分叉后，读取最新记忆可能引入分叉点之后的信息；这应明确显示为外部召回的记忆及其来源，不伪装成继承的历史消息。

## 建议的读写时机

1. 新会话提供记忆入口、当前分支/思路身份及简短索引，agent 按任务选择详细记录。
2. 任务涉及新文件、模块或操作时增量召回；恢复旧会话时核实代码相关记忆是否仍有效。
3. 每次运行结束保存独立变更记录；出现明确决策、偏好或验证结果时及时更新长期知识，不只依赖会话关闭。
4. agent 生成语义内容，harness 负责身份绑定、写入持久化、索引更新、幂等与失败提示。
5. 中断时保存已经观察到的进展并标记不完整；不能把生成失败的摘要当成已完成写入。

## 存储位置与 Git 的待定点

建议先验证每个 worktree 内独立记忆目录：同列思路共享，不同 Git 分支不自动实时同步。若记忆受 Git 管理，新分支会继承起点提交中的记忆，合并时要处理记忆冲突；继承文件不等于其中的代码事实仍然有效。

如果以后需要全项目实时共享偏好，应由明确的共享存储/召回入口实现，不能把独立 worktree 内同名目录当成同一物理目录。

已确认沿用 MWF 的 Git 跟踪策略：共享持久记忆默认跟踪，并支持项目选择整体忽略；私有 local 记录始终排除 Git。保留已有项目的 track/ignore 选择。完整聊天记录与共享记忆区分保存，不因采用该策略自动纳入 Git。即使选择不跟踪，也应在删除 worktree 前保存相关记忆，避免历史会话失去知识来源。不要把跨分支共享单文件 handoff 当作默认方案。

## 集成路线与 MVP 验收

建议先验证复用 MWF 的长期知识能力，由 parallel_pi 单独保存会话记录与分支身份映射。若选定 `.memory/` 或新增作用域字段，必须显式适配运行时与协议；不要直接写入未知字段，或把 `.memory/` 宣称为现有 `.mwf/` 的兼容别名。

MVP 验收：新会话能按需找回已确认偏好；同列思路能找回有效分支结论；未确认假设不会自动成为规则；其他分支的事实不会误召回；每条记录可追溯来源；重复写入可去重；写入失败可见；刷新/重启不丢已保存记录。
